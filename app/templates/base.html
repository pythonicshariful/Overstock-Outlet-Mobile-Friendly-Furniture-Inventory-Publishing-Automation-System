Interactive User Manual & 1-Click Connection Guide
Zero .env Files Needed! All Facebook Page and Instagram Business connections are done 100% from the Web UI and saved directly in the database.
Step-by-Step: Connect Facebook Page (and Optional Instagram) in 2 Minutes
  1. Facebook-Only vs. Facebook + Instagram:
    If your Instagram is not linked yet, the system automatically connects Facebook Only! To also connect Instagram, follow the "How to Connect Instagram with Facebook" box below at any time.
  2. Create or Open a Meta Business App:
    Click Meta for Developers → My Apps , click Create App → Other → Business.
  3. Open Graph API Explorer to Generate a Token:
    Click Meta Graph API Explorer . In the right sidebar:
    • Select your Meta App.
    • Under User or Page, select Get Page Access Token (or User Token).
    • Add these permissions (click any badge to copy):
      pages_manage_posts pages_read_engagement pages_show_list business_management instagram_basic instagram_content_publish
    • Click Generate Access Token, approve the popup for your Facebook Page, and copy the token.
  4. Paste into Our 1-Click Auto-Connect Wizard:
    Go to Admin Control Center → Connect FB & Instagram, paste the token into the 1-Click Auto-Connect box, and click "Auto-Discover & Connect"!
    The system will automatically connect your Facebook Page (and Instagram if linked; if Instagram is not linked yet, it connects Facebook-only!).
How to Connect Instagram with Your Facebook Page
  1. Switch Instagram to a Professional/Business Account: Open the Instagram app on your phone → Profile > Settings and activity > Account type and tools > Switch to professional account → choose Business.
  2. Link Instagram Inside Your Facebook Page: Open your Facebook Page on a computer → click Switch Now into the Page profile → go to Settings > Linked Accounts > Instagram → click Connect Account and log in with your Instagram username and password.
  3. Re-Run 1-Click Auto-Discover: Return to Admin → Connect FB & IG, paste a fresh token from Graph API Explorer, and click Auto-Discover & Connect. Both Facebook and Instagram will be linked!

How to Connect Multiple AI Clients from the UI

You can configure any or all of the 4 supported cloud AI providers below (plus the built-in Smart Retail Copy Engine which works out-of-the-box with zero API keys).

1. Google Gemini (Recommended – Free Tier Available + Photo Vision)
  1. Open Google AI Studio API Keys and sign in with Google.
  2. Click "Create API Key" and copy the key starting with AIza....
  3. Paste into Admin → AI Copywriting & Models → Gemini API Key and click Save AI Settings.
2. OpenAI GPT-4o / GPT-4o-mini (Photo Vision + Text)
  1. Open OpenAI Platform API Keys .
  2. Click "Create new secret key" and copy the key starting with sk-....
  3. Paste into Admin → AI Copywriting & Models → OpenAI API Key and click Save AI Settings.
3. Anthropic Claude (Photo Vision + Text)
  1. Open Anthropic Console Keys .
  2. Click "Create Key" and copy the key starting with sk-ant-....
  3. Paste into Admin → AI Copywriting & Models → Anthropic API Key and click Save AI Settings.
4. Groq Cloud (Ultra-Fast Llama Text)
  1. Open Groq Cloud API Keys .
  2. Click "Create API Key" and copy the key starting with gsk_....
  3. Paste into Admin → AI Copywriting & Models → Groq API Key and click Save AI Settings.

How to Post to Facebook Marketplace in 30 Seconds

Because Meta blocks automated bots on personal/consumer Marketplace feeds, our Marketplace Publishing Assistant prepares everything for a 1-tap copy-and-paste workflow:

  1. On any product card, tap "Marketplace" (or check Facebook Marketplace when saving a new product).
  2. Tap "1. Open Facebook Marketplace" to open Facebook's item listing screen.
  3. Tap "Copy Title", "Copy Price", and "Copy Description" to paste optimized retail copy with 1 tap.
  4. Upload the numbered product photos in order and tap Publish on Facebook.
  5. Tap "Mark as Published on Marketplace" to record the listing in your store log!
Floor Associate 60-Second Mobile Workflow
  1. Snap Photos: Tap "Add New Product" → "Open Camera" and snap 1–4 photos of the furniture piece.
  2. Enter Specs: Type the Title, Outlet Price, Retail Price (optional), Category, and Condition.
  3. Auto-Generate Description: Choose your AI engine (or leave on Auto) and tap 🪄 Auto-Generate. If you snapped a photo, Vision AI will inspect the furniture photo automatically!
  4. Save & Publish: Toggle on Facebook Page, Instagram, and/or Marketplace, and tap Save & Publish.
